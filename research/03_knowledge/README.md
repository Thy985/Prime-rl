# 03_knowledge — 知识消费层

这一层是把研究档案变成「未来的我能重新理解」的地方。

## 这是什么

`00_index` / `02_experiments` / `04_synthesis` / `05_process` 是**证据和索引**：
它们回答「发生了什么、证据在哪、结论是什么」。

`03_knowledge` 是**思考图**：它回答

> 我是怎么走到这个答案的？哪个实验推翻了哪个想法？
> 如果三年后只剩这张图，我还能不能重建这段研究？

## 三份文件的关系

| 文件 | 作用 | 谁读 |
| --- | --- | --- |
| `map.md` | 整条研究流程图（节点 + 关系） | 先读这个 |
| `nodes/` | 每个节点一份 12 节笔记 | 有疑问时深入 |
| `concepts/` | 术语索引（术语只是标签，不是入口） | 忘记术语时查 |
| `knowledge_graph.json` | 结构化数据（网页的 source of truth） | 程序 |
| `web/` | 可交互知识地图网页 | 想看图时 |

## 怎么读

1. 打开 `map.md`，沿着节点顺序看一遍（不是时间线，是**为什么走到下一步**）。
2. 对每个节点，先读 `## 1. 这里发生了什么`（大白话）和
   `## 7. 这改变了什么理解`（原来/现在）。
3. 想深究再读证据部分——证据链永远回溯到 `00_index` 和 `02_experiments`。
4. 术语记不住没关系，看 `concepts/`，每个术语都有一条「大白话等价物」。

## 本层的纪律

- **问题从节点产生，节点从流程产生。** 没有独立的「问题列表」。
- **被推翻的路不删除。** 每一次撤回、改名、缩水都是研究的一部分。
- **证据不改写。** 本层只引用 `00_index` / `02_experiments` 的结论，
  不制造自己的事实。
- **大白话优先。** 每个节点都能脱离术语被重新理解。
- **术语是标签。** `concepts/` 是索引，不是知识主体。

## 和主档案的分工

主档案（`00_index` 等）是**录音带**——记录发生了什么。
本层是**重听笔记**——记录我当时怎么想、现在怎么理解、下次怎么用。
