# N01 — 起点：奖励能塑造可迁移能力吗？

## 1. 这里发生了什么

在分支 `exp/reverse-text-pipeline` 上做反转文本任务（把字符串倒过来）：
想验证「用奖励信号训练，能不能让一个小模型学会一个能力，而且这个能力
在继续更新时不被破坏」。用了 LoRA SFT 和单卡离线 GRPO 两条路，做了三组
奖励消融（V1/V2/V3）。

## 2. 为什么走到这里

这是整个档案的第 0 步。当时的问题非常原始：**reward 能不能塑造能力**。
没有环境、没有 agent、没有 SWE——只想先确认训练管线本身可信。

## 3. 这里真正的问题

- Q1: 奖励函数的长相（lcs、位置、精确匹配）决定了学不学得会吗？
- Q2: 学会的能力在继续训练时会不会被覆盖？
- Q3: 我怎么知道测量到的「变好」是真的变好，而不是测量方式自己变了？

## 4. 我原来怎么想

以为会得到一个清晰的奖励形状结论：某种奖励 > 另一种奖励。
在低学习率下甚至看到「奖励上升且能迁移」的漂亮曲线。

## 5. 我做了什么

- SFT 建立基础能力：0/18 → 7/18 精确匹配（已验证）。
- GRPO 单卡跑通（sampler → verifier → reward → advantage → LoRA delta）。
- 三组奖励消融，学习率保持「非破坏性」。
- 用独立 held-out 评估，而不是训练内指标断言。

## 6. 得到了什么

两个头条结论**双双撤回**：
- 「奖励上升且能迁移」——撤回：协议 bug（训练/评估用了两套略不同的规则）。
- 「每个奖励都会摧毁能力」——撤回：是学习率破坏的，不是奖励问题
  （lr 1e-4 是破坏性更新 regime）。

真正留下的东西是方法：**先让测量不可疑，再谈能力**。

## 7. 这改变了什么理解

原来：奖励函数的形状决定学习结果，我可以比较奖励。
现在：任何能力断言都以「protocol 单一来源 + 非破坏性更新 regime」为前提，
这两条是从撤回中学到的，不是一开始就有的。

## 9. 专业术语

- reward ablation：我的理解——只改奖励、其他不动，看效果变不变；本项目含义——
  三组奖励消融是这条研究的第一块基石，但它必须先排除协议污染。
- protocol invariance：我的理解——训练/推理/评估用同一套规则；
  本项目含义——两条撤回结论都是违反它造成的。
- non-destructive lr：我的理解——更新一步不会把已有能力冲掉的学习率；
  本项目含义——消融必须在它下面读，否则看到的是优化器破坏，不是奖励效果。

## 10. 可迁移的东西

「测量仪器不能悄悄改写答案」是一个普遍原则：任何比较实验，
先证明两次测量用的是同一把尺，再讨论谁大谁小。
适用场景：奖励设计、评估协议、benchmark 复现、任何 A/B。

## 11. 还不知道什么

- known：SFT 能建 reverse-text 能力（0/18→7/18）。
- inferred：奖励形状可能仍有影响，但本实验无法区分它与协议污染。
- open：反转文本任务的成功率上限是多少；RL 管线在更大模型上的表现。
